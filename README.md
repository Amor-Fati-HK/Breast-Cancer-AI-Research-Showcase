# Multimodal Breast Cancer Detection (AI Research)

**CLASSIFIED RESEARCH REPOSITORY**

The source code for this project is currently strictly **PRIVATE** and closed-source, as the methodology and findings are pending publication in an international IEEE/Springer scientific conference. Access to the codebase may be granted to academic committees or recruiters upon legitimate request.

### Project Overview

Developed a state-of-the-art Deep Learning pipeline for medical image segmentation targeting breast cancer detection. The architecture transitions from baseline U-Nets to advanced Vision-Language Models (VLMs), integrated with a custom Refiner module.

###  Key Achievements

- **Performance:** Achieved an **89.71% Dice Coefficient** and **86.97% Accuracy** on the challenging CBIS-DDSM dataset.
    
- **Architecture:** Implemented in Python using TensorFlow/Keras.
    
- **Deployment:** Built a real-time, interactive UI using Gradio for clinical prediction visualization.
